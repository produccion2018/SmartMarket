# Smart Market POS

martMarket POS (Sistema de Supermercado) — SISTEMA DE GESTIÓN (CON PYTHON)

Tipo de Proyecto: Sistema de Caja y Control de Inventario para Supermercados

Tecnología: React + Vite, Tailwind CSS (Frontend interactivo) y preparación para Python (Flask/FastAPI) + SQLite3 (Backend a cargo de Mauro)

¿Qué es y qué función cumple?: Es un sistema integral para puntos de venta (POS) y supermercados. Permite simular el escaneo de productos, cálculo de totales, aplicación de descuentos, emisión de tickets y visualización del stock. Toda la interfaz gráfica y la interactividad de los botones están resueltas en el frontend, mientras que la lógica de la API, el backend en Python y la base de datos se desacoplan para que los desarrolles e integres por tu cuenta.

Prompt actualizado para desarrollar / generar este proyecto:

Actúa como un desarrollador Frontend Senior experto en UI/UX. Necesito que diseñes y desarrolles la aplicación frontend completa para un sistema POS de supermercado (SmartMarket) utilizando React y Vite, con un diseño moderno y limpio (puedes usar Tailwind CSS).

La aplicación debe ser puramente frontend y no debe incluir conexiones reales ni servidores de backend, ya que el backend y la API en Python (con FastAPI/Flask y SQLite3) los desarrollaré yo por mi cuenta.

Lo que sí necesito que programes completamente funcional a nivel visual y de interfaz es:

Una pantalla principal de caja / ventas donde se puedan agregar productos a un carrito, calcular subtotales, aplicar descuentos y presionar un botón de "Cobro" que simule la transacción exitosa y limpie la pantalla.

Una sección de gestión de inventario/stock con botones interactivos (para agregar, editar o eliminar productos de la vista).

Una estructura de carpetas limpia y ordenada (componentes, vistas, etc.), dejando comentarios claros en el código donde se indique exactamente en qué partes se conectará en el futuro la API de Python que haré yo mismo.
